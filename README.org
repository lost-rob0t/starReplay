* Star Replay
Record Messages being sent over the pub/sub network, then play them back to the msg broker and actors for debugging/testing.

Note, the api port cant be monitored, so in the future starRouter will have to bridge it.

** Install
#+begin_src shell
nimble install https://github.com/lost-rob0t/starReplay.git
#+end_src

*** debian
#+begin_src shell
sudo apt install libzmq liblmdb-dev
#+end_src
*** nixos
You may optionally install direnv to have it auto install deps apon directory
#+begin_src shell
nix-shell; nim c -d:release src/starReplay.nim
#+end_src

* Canonical document replay
Payloads are opaque: the recorder neither infers a document version nor rewrites
historical recordings. The immutable starRouter dependency at
=cda4722013a94df46c309a7c14c177caf79bfae5= preserves already-serialized strings
without JSON-encoding them a second time. That allows flat StarIntel 0.10.1
payloads (including false/null/opaque extensions) to survive record/replay.
Validation remains the ingest boundary's responsibility; replaying a historical
record does not make it canonical. The dependency's native =test_payload.nim=
roundtrip gate covers repeated string relay and JsonNode serialization.
